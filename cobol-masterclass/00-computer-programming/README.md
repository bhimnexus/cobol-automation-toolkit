# Computer Programming — Introduction

---

## 1. What Is a Computer Program

A **computer program** is a set of instructions written in a programming language that enables a computer to process data and produce meaningful information.

A computer cannot think or make decisions on its own.  
It can only perform actions based on the instructions given to it through programs.

In simple terms:

> A program tells the computer **what to do**, **how to do it**, and **in what sequence**.

---

## 2. Types of Computer Programs

Computer programs can be broadly classified into **two main types**.

---

### 2.1 Operating System Programs

**Operating system programs** control the overall operation of the computer system.

They are responsible for:
- Managing memory
- Managing CPU and processing time
- Managing input and output devices
- Managing files and storage
- Providing an environment for application programs to run

Examples:
- z/OS (IBM Mainframe)
- Windows
- Linux
- UNIX

Operating system programs are **system-level software** and are not written as part of normal application development.

---

### 2.2 Application Programs

**Application programs** are programs written to perform specific tasks required by users or businesses.

These programs:
- Read input data
- Process the data according to business rules
- Produce output or information needed by users

Examples:
- Payroll systems
- Banking transaction systems
- Insurance claim processing systems
- Inventory management systems

📌 **COBOL is primarily used to write application programs**, especially business-oriented applications.

---

## 3. Software — A General Term

The term **software** is used to describe **all types of computer programs**, including:
- Operating system programs
- Application programs
- Utility programs

Relationship:
- **Hardware** → Physical components of a computer
- **Software** → Programs that run on hardware

---

## 4. Input–Process–Output (IPO) Concept

Most application programs follow a common logical flow called the **IPO cycle**.

### IPO stands for:

1. **Input**  
   - Reading data from files, databases, terminals, or devices

2. **Process**  
   - Applying calculations, validations, and business rules

3. **Output**  
   - Producing reports, updated files, messages, or screen displays

This model forms the basis of most business applications.

---

## 5. Information Systems

An **Information System** is a set of computerized business procedures designed to:
- Collect data
- Process data
- Store data
- Produce meaningful information

Examples:
- Banking Information System
- Payroll Information System
- Insurance Policy Management System

📌 COBOL is widely used in building **business information systems**.

---

## 6. Application Program Development Process

The development of an application program follows a structured process.

---

### Step 1: Determine Program Specifications
- Understand business requirements
- Identify inputs, outputs, and processing rules

---

### Step 2: Design the Program
- Plan the program structure
- Use flowcharts or pseudo-code for logic design

---

### Step 3: Code the Program
- Write the program using a programming language (such as COBOL)

---

### Step 4: Compile the Program
- Convert source code into machine-readable form
- Identify and correct syntax errors

---

### Step 5: Test the Program
- Execute the program with test data
- Verify correctness of results

---

### Step 6: Document the Program
- Add comments and documentation
- Facilitate future maintenance and enhancements

---

## 7. Key Points to Remember

- A program is a set of instructions given to a computer.
- There are two main types of programs:  
  **Operating system programs** and **Application programs**.
- COBOL is used to develop **business application programs**.
- Most applications follow the **Input–Process–Output** model.
- Program development follows a structured lifecycle.
